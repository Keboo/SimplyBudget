### 2026-10-25: Mobile-first product usability
**By:** Kevin Bost (via Copilot)
**What:** Make mobile usability a first-class product requirement for SimplyBudget: new and changed user-facing screens and workflows must be deliberately designed and validated for phone-sized viewports as well as desktop, not merely shrink desktop layouts. Require responsive task-appropriate information hierarchy and controls, no unintended horizontal overflow or obscured primary actions, usable touch interactions, accessible labels and focus, and representative mobile workflow/browser checks.
**Why:** The user explicitly asked to make sure mobile-friendly design is maintained in the app going forward and requested that it be written into project requirements.
